      How it works

      Kinds
      task runs to the end. service and stream run until stopped. gui opens a window. interactive opens in a terminal. link is something to open.
      Needs
      What must exist first: a display, vcan0, a gamepad, a running drivetrain. Missing hardware or Pixi blocks the start; the rest are warnings. Re-check updates them.
      Uses
      Resources an item holds. Two items holding the same drivetrain, bridge port or gamepad nodes can't run together.
      Stopping
      Stop sends Ctrl-C to the item and everything it started. Ctrl-C in the devtool/billee-dev terminal stops the tool and all its runs.
      Editing
      Items live in devtool/catalog.json. Reload the page after saving.
      Keys
      / search, Esc clear search.
