    Help

    Kinds:
    task runs to completion. service runs until you stop it. stream prints until stopped. gui opens a window. interactive needs keyboard input and opens in a terminal. link is something to open.
    Needs:
    What must exist first (a display, vcan0, a gamepad, a running drivetrain). Missing ones are shown as warnings, and are checked again with Re-check.
    Uses:
    Resources the item holds. Two items that hold the same drivetrain, bridge port or gamepad nodes can't run together; the second one is blocked until the first is stopped.
    Stopping:
    Stop sends Ctrl-C to the item and everything it started. Ctrl-C in the terminal running devtool/billee-dev stops the tool and all its runs.
